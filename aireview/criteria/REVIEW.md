# Критерии ревью проекта microbit-shooter («Защитник Неба»)

Контекст конвенций — [AGENTS.md](../AGENTS.md), архитектурных инвариантов —
[ARCHITECTURE.md](../ARCHITECTURE.md). Здесь — только проверка соответствия.

## Общие

1. Стек строго по плану: ванильный JS (ES-модули), Canvas 2D, Web Audio, Web Serial. Никаких внешних рантайм-зависимостей, никакой сборки. Гейты обязательны: `npm run check` (ESLint 10 + Prettier + Vitest) зелёный.
2. Идентификаторы в коде — английские; комментарии, UI-тексты, README — русские. Комментарии объясняют «почему», а не пересказывают код.
3. Нет мёртвого кода, закомментированных фрагментов, отладочных `console.log` (допустим `console.warn`/`console.error` для реальных проблем окружения).
4. Безопасность: отсутствие `eval`/`new Function`, `innerHTML` с динамическими данными; localStorage в `try/catch`; сервер отдаёт файли только из корня проекта (защита от path traversal), выставляет `X-Content-Type-Options`.

## USB-коннектор (js/microbit/serial.js)

5. Web Serial по референсу: `requestPort` с фильтром VID `0x0d28`/PID `0x0204`, открытие на 115200 бод; `isSupported()` проверяет `navigator.serial` до любых вызовов.
6. Строчный протокол обязан буферизоваться до `\n`: USB-чанки не равны строкам; `\r` в конце строк погашен.
7. Обязательны: цикл чтения переживает обрыв USB (событие `disconnect` + падение reader → статус disconnected), ручное закрытие не считается обрывом, `NotFoundError` (отмена выбора порта) — не ошибка, `port.open` при занятом порту даёт понятное сообщение. Ошибка подключения не должна ломать игру — управление падает на клавиатуру. Отправка `BEEP` освобождает lock writer-а.

## Игра (js/game.js, js/render.js, js/input.js, js/main.js)

8. Игровой цикл на rAF, dt ограничен сверху (кламп ~50 мс), нет утечек: `destroy()` снимает слушатели и отменяет rAF.
9. Клавиатура не скроллит страницу (preventDefault у стрелок/пробела); пробел не «нажимает» сфокусированную кнопку повторно.
10. Механика по ТЗ: прицел в центре кабины; стрелки или наклон платы (deadzone); выстрел пробел/A+B; попадание — пересечение прицела и цели в момент выстрела; партия 30 с; счёт сбитых и очки видны сбоку (HUD); кнопки СТАРТ/ЗАВЕРШИТЬ/ИГРАТЬ СНОВА работают; звук выстрела, взрыв с анимацией и звуком, гул мотора только во время игры.
11. Ресурсы не создаются в горячем цикле без нужды (градиенты/спрайты неба и кабины кэшируются).
12. Аудио: AudioContext создаётся/резюмится только по жесту пользователя; мотор останавливается при любом завершении партии (таймер, кнопка, ошибка).

## HTML/CSS

13. Один canvas 640×480, масштабирование с сохранением пропорций, `image-rendering: pixelated`, сканлайны — псевдо-слой поверх, не перехватывают клики.
14. Доступность-минимум: кнопки — настоящие `<button>` с русскими подписями, `lang="ru"`, `<noscript>`-сообщение.
15. Стиль 16-bit: плоская палитра, пиксельный шрифт с кириллицей (fallback monospace), никаких стоковых картинок.

## Тесты и деплой

18. Новая/изменённая логика покрыта тестами в `tests/`: чистая логика — node-окружение, DOM — докблок `// @vitest-environment happy-dom`; тесты детерминированы (без гонок на таймерах). Юнитами не покрываются только `render.js`, `audio.js`, `main.js` (канвас/WebAudio/композиция — см. coverage-exclude в `vitest.config.js`).
19. Совместимость со статик-хостингом (Vercel): в `index.html`, CSS, `manifest.webmanifest` и `sw.js` только относительные пути (`./`), никаких абсолютных `/...`; статику не нужно собирать; `vercel.json` не ломает заголовки (sw.js — no-cache).

## Мобильная версия и PWA

20. Touch-режим (`pointer: coarse`): прицел — Accelerometer API, при его отсутствии/отказе — экранный D-pad; выстрел — тап по канвасу (desktop-мышь не стреляет); компактный HUD без боковой панели; landscape принудительно (fullscreen + orientation.lock, CSS-поворот в portrait как резерв). Приоритеты ввода — как в ARCHITECTURE.md «Режимы ввода». Индикатор micro:bit отражает реальный статус коннектора.
21. PWA: `manifest.webmanifest` валиден и отдаётся как `application/manifest+json`; иконки 192/512+maskable существуют и генерируются только `scripts/generate-icons.mjs`; `sw.js` кэширует same-origin cache-first, Google Fonts — stale-while-revalidate; новая статика shell добавлена в `CORE_ASSETS` с bump `VERSION`; регистрация SW только на http/https.

## Прошивка и инфраструктура

16. `firmware/microbit-firmware.ts` компилируется в MakeCode: шлёт `A:roll,pitch` по USB-serial ~10 раз/с, `FIRE` по A+B, `START` по встряске, реагирует на `BEEP`; скорость 115200 задана явно.
17. `server.mjs` — только статика из корня, MIME-типы корректны (в т.ч. `.ts` как text/plain, `.webmanifest` как application/manifest+json), порт из `PORT`.
