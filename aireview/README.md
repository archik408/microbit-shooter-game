# aireview/ — процесс ревью

Папка обслуживает цикл авторевью (команда `/review-loop`, см.
`.zcode/commands/review-loop.md`). Что лежит здесь:

- **`PLAN.md`** — план **текущей** задачи: перезаписывается на каждый цикл
  «план → реализация → ревью». Историю не копим — источник правды о прошлых
  изменениях это git.
- **`criteria/REVIEW.md`** — живые критерии приёмки кода: их читает
  ревьюер-субагент и разработчик перед сдачей. Правятся отдельной задачей,
  не походя.

Разделение с корневыми документами (не дублируем, а ссылаемся):

- [AGENTS.md](../AGENTS.md) — конвенции и команды проекта (как работать);
- [ARCHITECTURE.md](../ARCHITECTURE.md) — архитектурные решения и
  инварианты механики (как устроено);
- `criteria/REVIEW.md` — проверка соответствия: и конвенциям, и
  архитектуре, и плану задачи (насколько код готов к приёмке).
