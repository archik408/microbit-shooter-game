# ARCHITECTURE.md — архитектура «Защитник Неба»

Дополняет [AGENTS.md](AGENTS.md): там — конвенции и команды, здесь —
зафиксированные решения, слои и инварианты игровой механики. Правила
приёмки кода — в [aireview/criteria/REVIEW.md](aireview/criteria/REVIEW.md).

## Ключевые решения

| Решение                                  | Почему                                                                                                                      |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ванильные ES-модули, без сборки          | игра деплоится на Vercel как есть; ноль зависимостей рантайма = ноль риска supply-chain и вес репозитория                   |
| Мир 320×240 → canvas 640×480, апскейл ×2 | честные «толстые пиксели» 16-bit: любой примитив, нарисованный в мире, квантуется итоговым масштабированием без сглаживания |
| Кабина и HUD на полном разрешении        | «железо игрока» поверх игрового мира; мир трясётся при взрыве — кабина стабильна                                            |
| Процедурные ассеты, статика кэшируется   | небо (дизеринг полос), кабина, облака рисуются один раз в offscreen-канвасы; в покадровом коде только `drawImage`           |
| Процедурный Web Audio                    | ни одного аудиофайла; вся «квадратность» — осцилляторы и шумовые буферы                                                     |
| micro:bit по USB (Web Serial)            | надёжнее BLE: без pairing, автоподключение к разрешённому порту; Web Bluetooth был первой реализацией и осознанно заменён   |
| Статический сервер только для localhost  | secure context для Web Serial + ES-модули не грузятся с `file://`; на Vercel сервер не нужен (HTTPS — тоже secure context)  |
| Шрифт: Press Start 2P + Pixelify Sans    | PS2P — каноничный 16-bit шрифт, но без кириллицы; по-глифовый fallback на Pixelify Sans держит русский UI без split-шрифтов |
| Плоские силуэты врагов без обводок       | чёрные stroke-рамки превращали самолёты в «квадраты»; чистые заливки читаются как пиксель-арт                               |
| PWA (manifest + SW + иконки)             | установка как standalone-приложение и офлайн; весь shell кэшируется, тянется только Google Fonts                            |

## Режимы ввода (финальное решение)

Приоритет источника абсолютной позиции прицела — первый живой в списке:
`клавиатура/D-pad (0.8 с после нажатия) → micro:bit → акселерометр телефона`.
Все источники наклона проходят одну рамку (deadzone 6°, полный ход 38°).

| Устройство | Прицел                        | Выстрел        | Старт          |
| ---------- | ----------------------------- | -------------- | -------------- |
| Desktop    | стрелки (скорость 1.35 экр/с) | пробел         | Enter / кнопка |
| micro:bit  | наклон платы (USB-serial)     | A+B            | встряска       |
| Телефон    | Accelerometer API (30 Гц)     | тап по канвасу | кнопка СТАРТ   |
| Телефон*   | экранный D-pad (4 стрелки)    | тап по канвасу | кнопка СТАРТ   |

\* D-pad — fallback, когда `Accelerometer` отсутствует или не стартовал
(iOS Safari и отказы в разрешении). D-pad и клавиатура пишут в один
`InputController.keys`, поэтому приоритеты и авто-repeat общие.

Наклон телефона: крен = atan2(x, z), тангаж = atan2(y, z); для
`landscape-secondary` оси зеркалятся (`orientationSign`). Знаки выверены
для landscape-primary — при инверсии на конкретном устройстве менять
только `orientationSign`, не рамку наклона.

## Мобильный layout (финальное решение)

- Детект `pointer: coarse` (в `main.js`), дальше два режима рендера:
  - **panel** (desktop): боковая HUD-панель, зона прицела `x ∈ [13, 244]`;
  - **compact** (телефон): панель скрыта, сверху строка
    «СЧЕТ · РЕКОРД · СБИТО · ВРЕМЯ», зона прицела расширяется до `307`.
    Границы зон — `Renderer.aimBounds` (единственный источник), у `Game`
    есть fallback-константы для тестов.
- Touch-политика: `html/body` — `touch-action: manipulation` (двойной тап
  не зумит, pinch остаётся), игровой ввод (канвас, `.joy-btn`) — `none`;
  `user-select: none` на `body` — тапы не выделяют текст.
- Landscape принудительно: на старте `requestFullscreen()` +
  `screen.orientation.lock('landscape')` (Android); CSS-резерв — в
  portrait кабинет поворачивается `rotate(90deg)` с размерами
  `u = min(24vh, 32vw)` (поворот раздаёт vh/vw местами).
- Индикатор micro:bit — инлайн-SVG в статус-чипе; `.chip-connected`
  зажигает его зелёным + glow. Чип показывает реальный статус коннектора.
- На телефоне (`pointer: coarse`, обе ориентации) статус-чип и блок
  `.help` скрыты через CSS — на маленьком экране они вытесняют заголовок
  и кнопки меню.

## PWA (финальное решение)

- `manifest.webmanifest`: `id`/`start_url`/`scope: "./"`, `display:
"standalone"` + `display_override`, `launch_handler`, `orientation:
"landscape"`, тема `#0a0c10`, иконки 192/512 + maskable, скриншоты
  narrow + wide (богатый install-диалог Android).
- Иконки и промо-скриншоты — артефакты `scripts/generate-icons.mjs`
  (PNG-энкодер на `node:zlib`, пиксель-арт): перегенерация командой,
  руками не править. Регрессионные проверки обвязки — `tests/pwa.test.js`.
- `sw.js` (версия `sky-defender-vN`): same-origin GET — cache-first, ядро
  префетчится на install; Google Fonts — stale-while-revalidate; смена
  версии кэша = bump `VERSION`. Пути только относительные (`./`) —
  проект живёт на собственном домене Vercel (относительные пути — для переносимости на любой статик-хостинг).
- Регистрация SW — в `main.js`, только на http/https; iOS-мета — в
  `index.html` (`viewport-fit=cover`, apple-/mobile-web-app-capable).
- Установка: в меню кнопка «УСТАНОВИТЬ ПРИЛОЖЕНИЕ» по событию
  `beforeinstallprompt` (Chrome/Android, показать промпт можно один раз);
  iOS — «На экран Домой» из Safari, кнопки там не будет.

## Слои и поток данных

```
main.js — композиция: создаёт подсистемы, кнопки, оверлеи. Ничего не знает о механике.
  └─ game.js — единственный владелец игрового состояния
       │        (mode, score, timeLeft, planes[]). Не касается DOM и рисования.
       ├─ render.js  — рисует; владеет чисто визуальными сущностями
       │              (облака, взрывы, вспышки, попапы) и их анимацией.
       ├─ input.js   — ввод: aim {x,y} ∈ 0..1 + edge-сигнал выстрела
       │              (consumeFire). Клавиатура и плата сводятся к одному API.
       ├─ audio.js   — звук по событиям игры; сам молчит, пока не вызовут.
       ├─ microbit/serial.js — транспорт: строки протокола ↔ latest{roll,pitch},
       │                       события fire/start, статус подключения для UI.
       └─ math.js    — clamp/lerp/randomBetween: общие хелперы нижнего слоя.
```

Правила слоёв: зависимости только вниз; `game.js` не знает про DOM,
`render.js` не принимает игровых решений; crosshair-координаты и хитбоксы
(в т.ч. для debug-отрисовки) считает `game.js` (`crosshairX/Y`,
`hitHalfSize`), рендер только рисует то, что ему дали.

Кадр (rAF, dt клампится до 50 мс): `input.update(dt)` → `game.update(dt)`
(спавн, физика самолётов, попадания, таймер) → отрисовка мира и сущностей →
кабина + HUD. Меню — attract mode: тот же цикл, но без прицела и счёта.

## Инварианты игровой механики

Эти константы и правила зафиксированы тестами и ревью; менять — только по
явной задаче (см. AGENTS.md).

- **Координаты**: вся логика — в мире 320×240 (экран = ×2). Рабочая зона
  прицела задаётся layout-режимом (`Renderer.aimBounds`): panel —
  `x ∈ [13, 244]` (справа HUD-панель), compact — `x ∈ [13, 307]`;
  `y ∈ [13, 186]` (снизу — приборная доска). Спавн врагов:
  `x ∈ [38, 210]`, `y ∈ [34, 150]`.
- **Прицел**: `aim` нормализован в 0..1. Клавиатура/D-pad — скорость 1.35
  экрана/с с экспоненциальным сглаживанием. Наклон (плата или телефон) —
  абсолютная позиция: мёртвая зона 6°, полный ход 38°, данные свежие
  ≤ 1.2 с; нажатые стрелки/D-pad подавляют наклон 0.8 с (управления не
  спорят). `blur` окна сбрасывает клавиши.
- **Попадание** — как в оригинале на LED-матрице: пересечение прицела и
  хитбокса `(15·sc + 7) × (11·sc + 6)` **в момент выстрела** (единственный
  источник формулы — `Game.hitHalfSize`, включая debug-отрисовку); среди
  пересекающихся сбивается ближний (максимальный `sc`). Кулдаун 220 мс.
- **Партия** 30 с; интервал спавна 1.5 → 0.95 с к концу. Жизненный цикл
  врага: подход 3.2 с (`sc` 0.34 → 1), жизнь 4.2 с, уход 1.2 с (свип + фейд).
- **Счёт**: +100 за сбитие; рекорд в localStorage (`sky-defender-best`,
  при чтении мигрирует максимум со старого `as-neba-best`) под `try/catch`;
  «★ НОВЫЙ!» — только строгое неравенство (повтор рекорда — не рекорд).
- **Состояния**: `menu → playing → gameover`; мотор звучит только в
  `playing` и гарантированно глушится в `finish()` и `destroy()`.
- **Аудио-политика**: AudioContext создаётся/резюмится по жесту
  пользователя; отказ `resume()` без жеста глотается.

## Протокол micro:bit (фиксирован)

Строки через `\n`, USB-serial 115200, VID `0x0d28` / PID `0x0204`.
Плата → браузер: `A:<roll>,<pitch>` (~10 Гц), `FIRE` (A+B), `START`
(встряска). Браузер → плата: `BEEP` (гудок при сбитии). Изменение формата —
это миграция прошивки ([firmware/microbit-firmware.ts](firmware/microbit-firmware.ts))
и буферизации в коннекторе. USB-чанки не равны строкам: разрез строго по `\n`,
`\r` гасится trim-ом.

## Точки расширения

- **Новый тип врага**: поля объекта `plane` в `game.js` + вариант палитры
  `PLANE_VARIANTS` в `render.js`.
- **Новая команда платы**: парсинг в `handleLine` (`serial.js`) + обработка
  в `input.js`/`main.js` + строка в прошивку.
- **Новый визуальный эффект**: только в `render.js` (`add*`/`updateEffects`/
  `drawEffects`); игровое последствие — поле в `game.js`.
- **Новый экран/оверлей**: разметка в `index.html`, показ/скрытие — только
  через `handleState` в `main.js`.

## Чего не делать

- Не вводить сборку, фреймворки и рантайм-зависимости.
- Не рисовать из `game.js` и не хранить игровое состояние в `render.js`.
- Не создавать канвасы/градиенты/спрайты в покадровом коде.
- Не выносить числа баланса механики из именованных констант `game.js`.
- Не дублировать в коде то, что уже зафиксировано здесь: менять — так
  вместе с этим файлом.
