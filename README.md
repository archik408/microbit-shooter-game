# Защитник Неба — HTML5-порт micro:bit-игры

Кабинный 16-bit шутер в духе Sega: по центру — прицел, из облаков на нас
летят вражеские самолёты «в фас», сбиваем их за 30 секунд. Порт
MakeCode-игры с BBC micro:bit (там механика была на LED-матрице 5×5:
наклон двигал цель, A+B — выстрел, встряска — старт).

## Запуск

```bash
npm install   # один раз: только dev-инструменты
npm run dev   # или: node server.mjs
```

Открыть **http://localhost:8080** (Chrome или Edge). Сервер нужен обязательно:
Web Serial работает только в secure context, а ES-модули не грузятся с `file://`.

## Управление

| Действие         | Клавиатура           | micro:bit         | Телефон                 |
| ---------------- | -------------------- | ----------------- | ----------------------- |
| Прицел           | стрелки              | наклон платы      | наклон телефона / D-pad |
| Выстрел          | пробел               | кнопки A+B вместе | тап по экрану           |
| Старт            | Enter / кнопка СТАРТ | встряхнуть плату  | кнопка СТАРТ            |
| Завершить партию | кнопка ЗАВЕРШИТЬ     | —                 | кнопка ЗАВЕРШИТЬ        |

Без подключённой платы игра полностью работает с клавиатуры.

### Мобильная версия

На телефоне игра сама переводится в landscape (полный экран + блокировка
ориентации; если браузер не позволяет — экран поворачивается средствами CSS).
Прицел управляется наклоном телефона (Accelerometer API); если сенсор
недоступен или не выдано разрешение — появляется полупрозрачный экранный
джойстик со стрелками. Выстрел — тап по экрану, счёт — компактной строкой
сверху вместо боковой панели. Индикатор в чипе слева сверху горит зелёным,
когда micro:bit подключён.

## Подключение micro:bit (USB)

1. Откройте https://makecode.microbit.org, новый проект, режим JavaScript.
2. Вставьте содержимое [`firmware/microbit-firmware.ts`](firmware/microbit-firmware.ts).
3. Download → скопируйте `.hex` на подключённую плату (монтируется как флешка).
4. Подключите плату к компьютеру USB-кабелем и в игре нажмите
   «ПОДКЛЮЧИТЬ MICRO:BIT» — выберите порт «BBC micro:bit» в диалоге браузера.

Связь — Web Serial: браузер открывает виртуальный COM-порт платы
(VID `0x0d28`, PID `0x0204`, 115200 бод), как в референсе
`nextjs-boilerplate/components/microbit-connector`. Прошивка шлёт в браузер
строки, разделённые `\n`:

- `A:<roll>,<pitch>` — углы наклона ~10 раз/с;
- `FIRE` — нажаты A+B;
- `START` — встряска.

Браузер при сбитии отправляет на плату `BEEP` (короткий гудок 147 Гц — как
тон в оригинальной игре). После первого разрешения порта игра подключается
к micro:bit автоматически при перезагрузке страницы и при переподключении
USB-кабеля.

Web Serial доступен в Chrome/Edge на desktop (нужен `localhost` или HTTPS);
в Safari и Firefox его нет — там игра остаётся на клавиатуре. Если порт
«занят», закройте мониторы COM-порта (MakeCode, PuTTY и т.п.).

## Механика (соответствие оригиналу)

- Попадание = прицел совмещён с самолётом **в момент выстрела** (аналог
  проверки `X==2 && Y==2` перед `Выстрел()` в MakeCode-версии).
- Партия 30 секунд (`время_игры = 30000`), очки за сбитые самолёты,
  рекорд хранится в localStorage.
- Спавн врагов учащается к концу партии, уцелевшие самолёты уходят с экрана.

## Деплой на Vercel

Игра — статика без сборки: Vercel выкладывает её как есть, никакой
конфигурации не нужно. `vercel.json` только добавляет заголовки
(`nosniff` всем файлам и `no-cache` для `sw.js`, чтобы обновления
service worker-а приходили сразу).

Через сайт:

1. Запушьте репозиторий на GitHub/GitLab.
2. vercel.com → Add New… → Project → импортируйте репозиторий.
3. Framework Preset: **Other** (без build-команды) → Deploy.

Или через CLI:

```bash
npx vercel          # превью
npx vercel --prod   # продакшен
```

Итог: `https://<project>.vercel.app`. HTTPS — secure context, Web Serial
и PWA работают так же, как на localhost. Локальный `npm run dev` нужен
только для разработки (см. «Запуск»).

## Установка как приложение (PWA)

Игра — полноценное PWA: работает офлайн (service worker кэширует игровой
shell) и устанавливается как standalone-приложение.

- **Android / Chrome, Edge**: меню браузера → «Установить приложение»
  (или иконка установки в адресной строке).
- **iOS / Safari**: «Поделиться» → «На экран “Домой”».
- После установки игра запускается без адресной строки, в landscape.

Иконки генерируются командой `node scripts/generate-icons.mjs` (правки
графики иконок — только в этом скрипте, не в готовых PNG).

## Структура

```
index.html, css/style.css     — экран-«кабина», оверлеи, D-pad, PWA-мета
js/main.js                    — сборка, кнопки, touch-режим, регистрация SW
js/game.js                    — состояния, цикл, спавн, попадания, таймер
js/render.js                  — 16-bit рендер (мир 320×240 → ×2, HUD panel/compact)
js/input.js                   — клавиатура, D-pad, micro:bit, акселерометр
js/audio.js                   — процедурные звуки (Web Audio): мотор, выстрел, взрыв
js/microbit/serial.js         — USB-коннектор micro:bit (Web Serial)
js/math.js                    — общие математические хелперы
manifest.webmanifest, sw.js   — PWA: standalone-установка и офлайн
icons/, scripts/generate-icons.mjs — иконки PWA и их генератор
firmware/microbit-firmware.ts — прошивка MakeCode для платы (USB serial)
server.mjs                    — статический сервер без зависимостей (localhost)
tests/                        — Vitest: serial, input, game, math, server
vercel.json                  — заголовки для деплоя на Vercel
AGENTS.md, ARCHITECTURE.md    — конвенции и архитектура проекта
aireview/                     — процесс ревью (см. aireview/README.md)
```

`http://localhost:8080/?debug=1` — хитбоксы, состояние ввода, FPS и доступ
к объекту игры из консоли (`window.game`).
